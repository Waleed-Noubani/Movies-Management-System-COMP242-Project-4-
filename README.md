## ✨ Features
- 🎬 Add, update, delete movies
- 🔍 Search by title or year
- 🔃 Sort ascending / descending
- 📊 Statistics per AVL tree (max & min rating)
- 💾 Save & load from file

---

## 🛠️ Data Structures Used
- Hash Table with dynamic rehashing
- AVL Tree (self-balancing BST)
